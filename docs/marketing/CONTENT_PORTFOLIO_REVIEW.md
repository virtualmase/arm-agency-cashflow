# Authority Content Portfolio Review Ledger

**Purpose:** Maintain the public ARM Agency content surface as a living operating asset. Each review asks whether the material is accurate, useful to a specific buyer decision, aligned with an active offer, and safe to continue distributing.

## Review Cadence

Review one or two assets each month and the entire portfolio each quarter. A material service, price, scope, security, policy, or domain change triggers an immediate review of affected assets.

| Asset | Stream | Buyer decision | Current conversion path | Review trigger | Decision options |
| --- | --- | --- | --- | --- | --- |
| AI Infrastructure Audit guide | ARM Mandate | Is a bounded diagnostic the right first step? | Diagnostic conversation | Audit scope, inputs, or price changes | Continue / update / retire |
| GEO Readiness guide | Swell GEO | Is a recurring GEO operating engagement appropriate? | Qualification conversation | Technical/measurement approach changes | Continue / update / retire |
| Network Participation guide | Arctura Network | Does the participation model fit the operating need? | Eligibility conversation | Participation rights or criteria change | Continue / update / retire |
| Operator Learning Path guide | Academy | Is education or implementation the appropriate first investment? | Pricing/Academy path | Curriculum or support boundary changes | Continue / update / retire |
| Bounded Agent-Stack Setup guide | Coreweaver | Is a defined implementation scope ready? | Technical scope conversation | Tool, access, security, or support boundary changes | Continue / update / retire |
| AI Discovery Readiness guide | Cross-stream | Which controllable discovery foundations should improve? | Readiness conversation | Platform guidance or evidence brief changes | Continue / update / retire |
| FAQ | Cross-stream | Can a buyer get accurate answers without a sales call? | Qualified conversation | Offer, pricing, portal, or policy change | Continue / update / retire |

## Quality Stop Conditions

Pause distribution and update an asset when it describes an unavailable offer, an expired price, a changed technical or security boundary, an unsupported outcome, a stale external claim, a broken conversion path, or a buyer decision the agency no longer wants to serve. It is better to withdraw or narrow a weak asset than to preserve publication volume.

## Learning Questions

The portfolio review should answer the following questions with actual sales, client, content, and operational evidence where available.

| Question | Evidence to use |
| --- | --- |
| Which guide helped a qualified buyer ask a better question or make a clearer decision? | Discovery notes, shared links, relevant inbound, sales follow-up. |
| Which content created confusion or unsupported expectations? | Misaligned inquiries, repeated clarification, proposal review, client feedback. |
| Which service boundary needs clearer public explanation? | Scope changes, lost reasons, onboarding friction, delivery escalations. |
| Which public fact or technical statement needs source review? | Evidence brief, service playbook, provider documentation, owner confirmation. |
| Which content should be updated, repurposed, or retired? | Review card decision and quality stop conditions. |
