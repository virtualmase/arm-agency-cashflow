# ARM Agency Keyword Cloud and Content Decision Map

**Prepared:** August 19, 2026  
**Owner:** ARM Agency  
**Status:** Internal planning artifact. It is not a demand forecast, ranking plan, publishing calendar, or authorization for automatic public-content creation.

## Purpose

This map expands ARM Agency’s keyword cloud as a **decision-language system**. Its purpose is to help qualified readers find the existing guide that matches their operating constraint, while preserving the library’s source, scope, and claim-safety standards.

> **Operating position:** ARM Agency helps accountable teams make public information, AI operations, and bounded technical interventions easier to understand, review, and improve. It does not promise rankings, AI citations, rich results, model mentions, traffic, leads, revenue, compliance, or risk elimination.

The map deliberately avoids a “one page per keyword variation” strategy. Google’s current guidance emphasizes helpful, non-commodity content and warns against scaled pages created principally to manipulate rankings or generative responses.[1] The right unit of expansion is a **buyer decision with a source plan**, not a search phrase.

## Decision Rules

| Rule | How it applies |
| --- | --- |
| One decision per public resource | Every phrase group must route to one existing guide or a future private brief with a distinct reader decision. |
| Evidence first | A phrase cluster receives a source record before it can influence public copy or a new resource brief. |
| Existing-library preference | Improve descriptions, internal links, headings, and qualified CTA context before proposing a net-new guide. |
| No exact-match inflation | Do not manufacture pages for fan-out phrases, feature lists, or keyword variants. |
| No demand fabrication | The map contains no search-volume, difficulty, traffic, ranking, citation, lead, or revenue claims. |
| Guide-level signal hold | Net-new public guides remain on hold until route-specific CTA, qualified-conversation, or purchase evidence justifies a single uncovered decision. |
| Human review | Any future public copy must pass source, claim, internal-link, and named-reviewer checks. |

## Signal Baseline

The current 30-day first-party event review records **89 homepage page views** and **one homepage checkout-start event**, with no guide-path page views, guide-level CTA events, qualified lead context, or completed purchases. This does not show which keyword or content theme is commercially relevant.

**Current action:** Use the cloud to improve language consistency and internal navigation around existing decision resources. Do not use it to announce demand, publish keyword-volume claims, or release a new content cluster.

## Editorial QA Checklist

Before an existing-page revision or any future brief becomes public, confirm all items below.

| Check | Required evidence |
| --- | --- |
| Reader decision | One specific audience, operating moment, and next decision. |
| Source class | Primary-source URL, date checked, exact support, and stated limit. |
| Page fit | An existing route genuinely addresses the language; otherwise the phrase remains private. |
| Claim boundary | No outcome, ranking, citation, traffic, lead, revenue, compliance, or security guarantee. |
| Internal route | Parent, related guide, and qualified conversion path are descriptive and relevant. |
| Technical baseline | Server-rendered visible content, canonical metadata, sitemap eligibility, accurate schema, and accessibility review where changed. |
| Approval | Named human reviewer approves public use; no automated publishing path is enabled. |
