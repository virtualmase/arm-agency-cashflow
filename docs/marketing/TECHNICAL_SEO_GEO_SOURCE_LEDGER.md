# Technical SEO and GEO Source Ledger

**Purpose:** This ledger maps public claims in the ARM Agency AI Discovery Operating System cluster to primary, externally maintained guidance. It is a source-control document, not a promise of search visibility, model inclusion, rich-result display, traffic, citation, or commercial outcomes.

| ID | Authority and URL | Supported public guidance | Explicit boundary for ARM copy |
| --- | --- | --- | --- |
| G-01 | [Google Search Central: Optimizing your website for generative AI features](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) | Google states that foundational SEO practices remain relevant to its generative AI search features, and emphasizes useful, non-commodity, people-first content and a clear technical structure. | Do not claim that GEO tactics, `llms.txt`, special markup, chunking, or generic content volume guarantee visibility in Google Search or any generative experience. |
| G-02 | [Google Search Central: JavaScript SEO basics](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics) | Google describes crawling, rendering, and indexing; recommends descriptive titles and snippets; and notes that server-side or pre-rendering benefits users and crawlers. It also identifies `<a href>` links as the crawlable-link pattern. | Do not represent a JavaScript framework, SSR, a canonical tag, or internal links as a guarantee of indexing, rankings, or model inclusion. |
| G-03 | [Google Search Central: General structured data guidelines](https://developers.google.com/search/docs/appearance/structured-data/sd-policies) | Structured data must represent visible, relevant, current, and non-misleading page content. Correct markup enables eligibility; it does not guarantee a rich-result appearance. | Do not use JSON-LD to add hidden claims, fabricated reviews, ratings, affiliations, or outcomes. Do not promise rich results. |
| G-04 | [Google Search Central: Introduction to structured data](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data) | Google explains that structured data provides explicit clues about page meaning and recommends JSON-LD when it suits the site setup; validation and monitoring are part of implementation. | Use the Google documentation—not schema vocabulary alone—as the source of truth for Google behavior. |
| W-01 | [web.dev: Build agent-friendly websites](https://web.dev/articles/ai-agent-site-ux) | Browser agents may use screenshots, HTML, and the accessibility tree. The guidance recommends stable layouts, semantic interactive elements, associated labels, and clear actions. | Do not represent agent-friendly interface practices as a promise that any agent can transact, access private data, or complete a workflow. Authentication and payment boundaries remain intact. |
| G-05 | [Google Search Console Help: Generative AI performance report (Search)](https://support.google.com/webmasters/answer/16984139?hl=en) | Google’s report provides impression data for supported Search generative AI features and offers page, country, date, and device dimensions. The report is being rolled out to a subset of properties; recent data can be preliminary, and standard reporting limits and aggregation differences apply. | Do not call impressions citations, rankings, referrals, conversions, or revenue. Do not assume the report is available for every verified property or that it covers experimental features. |
| G-06 | [Google Search Central Blog: Introducing Search Generative AI performance reports](https://developers.google.com/search/blog/2026/06/gen-ai-performance-reports) | Google announced dedicated Search Console views for impressions in AI Overviews and AI Mode, with pages, countries, devices, and dates as report dimensions. | Treat this as a Google Search measurement input alongside first-party site signals, not a cross-platform or universal GEO measurement standard. |

## Editorial application

The planned public cluster should cite these sources when it describes search-system behavior, technical eligibility, structured-data quality, rendering, crawlable links, semantic actions, or limits on generative-search tactics. It should distinguish ARM Agency’s own operating advice from behavior stated by an external system.

When a new material claim is added, the content owner must record the source, review date, and scope boundary in the Public Claim Registry before publication.
